# Генератор тестов

> Консольная программа для генерации случайных тестов с перемешиванием вопросов и вариантов ответов. Поддерживает два режима: «Обучение» (с подсказками) и «Экзамен» (без подсказок). Автоматически подсчитывает результат и выставляет оценку.

# Как запустить проект
Склонируйте репозиторий:
git clone <url>
Создайте виртуальное окружение:
python -m venv .venv
Активируйте:
source .venv/bin/activate (Linux/macOS) или .venv\Scripts\activate (Windows)
Установите зависимости:
pip install -r requirements.txt
Запустите:
python main.py
Технологии и модули
Python 3.10+
Стандартные модули: string, collections, datetime
Без сторонних NLP-библиотек
